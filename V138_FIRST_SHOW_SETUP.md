# v1.13.8 — First-show recommendation and next-show tips

- Everyone chooses appears first in answer-format setup, with “Recommended for your first show” directly below the title. Newly created rooms default to this format; existing rooms and rematches retain their settings. The recommendation remains visible in setup for any host, without a first-time detection system or new tracking.
- At the Curtain Call, a short suggestion on host and player phones offers another answer format based on the show's common setting. Choices → written Easy; mixed Medium/Hard → written Easy and Medium; mixed Hard → all written; written → options for Hard or every question; individual preferences → a shared mixture. These are invitations, not automatic changes. The host already returns to the answer-format step on rematch.

To upgrade from v1.13.2, first run `supabase/upgrade_v1_13_5.sql` in Supabase SQL Editor (also provided separately).
