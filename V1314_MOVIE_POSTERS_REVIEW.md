# v1.13.14 — Name That Movie: Classic Posters (private review)

Adds a year-round category to v1.13.13 with 15 regular questions (five per level), two Final Word questions, and 17 title-masked JPEG assets. All images derive directly from the supplied files; no artwork is regenerated. The regular textual hints are retained for the bank only; normal play continues to use paid answer options and 50/50. Final Word follows the existing topic-preview and sequential hint rules. Original posters are not served or shown on answer reveal; the displayed answer is the movie title. No new SQL or environment variables. All existing question IDs, images, and availability settings are unchanged. Total library: 77 categories, 1,014 regular questions, 79 category-linked finals, 1,093 total. 71 finals eligible before category/season filtering.

**Private review only. Do not upload this archive to the public production deployment until the individual poster rights have been cleared.** The source website presents these as public-domain images; related archival references have been found, but not all exact poster versions or modern reproduction alterations have been independently confirmed. King Kong is a French-language edition, Gone with the Wind an unusual montage, and some references describe another poster edition. The audit CSV and IMAGE_CREDITS.json retain source candidates and limitations. A category toggle alone does not protect publicly served image files. For local review, the category is available by default like other categories. This is not a legal clearance opinion.

Images retain the source poster artwork with opaque, sometimes background-matched masks to hide title text. Some masks conceal surrounding content. Review the preview visually before final art approval; a more polished retouch may be appropriate for specific posters. No original poster is included in the public asset directory for this category. The original ZIP remains the authoritative source.

To test locally, extract the full package, install dependencies and use your existing local environment configuration, then start the development server. The patch is relative to v1.13.13; standard permissions and folder layout. For production, wait for rights review and any necessary revisions. No database changes required for local gameplay.

Validation: 122/122 engine tests, 72/72 UI contract tests and strict game type check passed. Full Next.js production build and live browser/device testing were not performed.
