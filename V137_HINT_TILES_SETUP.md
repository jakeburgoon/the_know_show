# v1.13.7 — Hint purchase controls and refundable Final Word selections

- Regular question hint purchases use a full-width navy control, gold lightbulb, action label and point price. The 50/50 status and Final Word revealed-hints panel use the same lightbulb icon. Regular purchases remain nonrefundable and the existing prices, timing, scoring and statistics remain unchanged.
- The two Final Word hint tiles are accessible toggle buttons. Tap Hint 1 to select it; tap Hint 2 to select both if necessary. Deselect Hint 2 to refund 500; deselect Hint 1 to refund both if selected. No separate purchase/undo buttons. Selected bulbs glow gold. The server accepts a target count of 0–2, validates available points, applies the exact net cost/refund, and rejects changes once the wager is locked or the question opens. Legacy purchase action is retained for older clients.
- Main instruction stands alone: “Tap to purchase or deselect a hint.” Smaller text beneath explains “Hints must be purchased in order, so selecting Hint 2 also selects Hint 1.” Hints remain hidden until the final question opens.
- Wager amount stays unchanged when affordable. A purchase that makes it unaffordable reduces the wager to the new maximum and displays a notice; refunds increase the maximum without restoring the previous wager. Correct/incorrect projections use the current post-hint balance.
- No new SQL or environment variables for an existing v1.13.5/v1.13.6 installation. Cumulative patch includes all changed files since v1.12.1; earlier migrations (v1.13.0, v1.13.2, v1.13.5) still apply if not yet installed.
