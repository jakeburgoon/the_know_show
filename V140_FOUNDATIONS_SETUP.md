## Changes
- TV sidebar stays mounted in all game phases, including results and Curtain Call. Full-stage reveals use a one-column layout and visually park the sidebar without removing its track-keyed iframe. A track change, music off, leaving TV mode, or navigating away intentionally removes/reloads playback. Browser/Suno behavior still requires real-device testing. Suno's cross-origin embed does not expose play, pause, volume, looping or playback position to the app. Hosts can choose tracks and turn music off remotely but still press Play on the display when required. Open only one actual TV display for audio; preview views have no audio. Multiple independent display tabs are not automatically coordinated.
- Landing has a display-only entry by show code. Host can create a room on a phone, join as a player, and open the read-only display route on a compatible spare phone/tablet/laptop/TV browser. Existing public display route polls live state without adding a participant or sending a host credential. Reconnect by opening it again. No display-presence handshake or native casting integration yet. Casting/mirroring and audio routing depend on the device, browser, and TV.
- Green Room gives setup instructions and copyable display link. Private host pairing is outside Additional settings. Scan the private QR with the phone camera if the show was created elsewhere; it grants full host rights and must not be shared with players. New pairing links put the bearer credential in a URL fragment rather than the request URL; legacy query links still work. The existing server credential check remains in place. Paired device skips the completed wizard, retains its own player credential, and opens Host View. Host/player tabs are equally prominent. Nonplaying hosts remain in Host View at show start. Remote host actions from Player View no longer insert a host-role snapshot into the player interface.
- Previous-answer review is available during the reveal and on the same round's board. It is no longer offered or accepted in the following draft or Final Word wagering. Already submitted disputes still block progression until resolved. The two former tests permitting cross-round review have been replaced with boundary tests that assert the new policy; same-round review regression remains.
